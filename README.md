# 瞬移 Bot 官方網站

本網站為「瞬移 Bot」官方網站靜態頁面。

## 檔案
- `index.html`：首頁
- `terms.html`：服務條款
- `privacy.html`：隱私政策
- `style.css`：網站樣式

## GitHub Pages
將以上檔案放在 Repository 根目錄，並在 Settings → Pages 選擇 `main` 分支與 `/ (root)`。
